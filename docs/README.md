# Documentation

This folder contains documentation for the DS UTH Exam Bank project.

## Files:

### deploy-turnstile.md
Documentation for deploying and configuring Cloudflare Turnstile integration with the project.

## Project Overview

The DS UTH Exam Bank is a web application that provides access to exam materials for the Department of Computer Science at the University of Thessaly.

### Key Features:
- File upload and download system
- Course-based organization
- Admin panel for content management
- File request system for missing materials
- Responsive design for all devices

### Technology Stack:
- Frontend: React with Material-UI
- Backend: Supabase (PostgreSQL, Storage, Auth)
- Deployment: Vercel
- Testing: Vitest

### Architecture:
- `/src` - React application source code
- `/supabase` - Supabase Edge Functions
- `/scripts` - Utility scripts for maintenance
- `/public` - Static assets
